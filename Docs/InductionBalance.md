# 발전 및 업그레이드 밸런스

기준 속도 2 Unity units/s, 무업그레이드 상태에서 자기선속 변화가 가장 큰 지점의 기본 출력은 1 W입니다. 같은 경로를 빠르게 통과하면 더 많은 에너지를 생산합니다. 같은 경로에서는 이동 속도 2배일 때 통과 보상도 2배입니다. 빠른 통과의 보상이 줄어들던 순간 출력 상한을 제거했습니다.

패러데이 법칙 `유도전압 = -N × dΦ/dt`와 저항 부하의 `전력 = 전압² / 저항`을 바탕으로 만든 게임용 근사 모델입니다. 실제 자석의 자기장 수치, 부하 회로 및 역학적 반작용을 시뮬레이션하지 않습니다. 코일 중앙에는 선속이 일정한 구간을 두고, 입구와 출구에서는 선속을 smoothstep으로 변화시킵니다. 전력은 이동 경로를 따라 적분합니다. 정지, 중앙의 작은 흔들기, 자기장 범위 밖의 이동은 재화를 생산하지 않습니다.

[패러데이 법칙 (OpenStax)](https://openstax.org/books/university-physics-volume-2/pages/13-1-faradays-law)

기존 UI 명칭과 단위를 유지합니다. Power는 정산한 보유 재화, WPS는 마지막으로 완료한 통과의 평균 생산량입니다. 물리적으로 누적 에너지는 J, 출력은 W에 해당합니다. 자석 중심이 InductionArea의 한쪽 Y 경계에서 반대쪽 Y 경계까지 통과했을 때 전력과 WPS를 함께 갱신하며, 다음 완료까지 WPS를 유지합니다. 영역 내부에서 시작한 첫 부분 이동에는 보상을 주지 않습니다. 이동 중 반대로 되돌아가면 해당 시도는 취소합니다. 소수 재화도 보관하고 Power에 소수 둘째 자리까지 표시합니다.

| 업그레이드 | 레벨별 효과 | 다음 레벨 구매 가격 |
| --- | --- | --- |
| 감은 수 | 레벨 1~7의 합으로 발전 기본치 1→3→6→10→15→21→28W | 500 / 3,000 / 18,000 / 108,000 / 648,000 / 3,888,000 |
| 전선 굵기 | 코일 높이와 발전 인식범위가 기본 높이의 10%씩 증가, 최대 150% | 750 / 2,250 / 6,750 / 20,250 / 60,750 |
| 코일 재질 | 전체 발전량에 매 레벨 ×2, 최대 ×32 | 5,000 / 25,000 / 125,000 / 625,000 / 3,125,000 |
| 자석 세기 | 자기장 +20%씩, 출력은 자기장 배율의 제곱 | 1,000 / 3,000 / 9,000 / 27,000 / 81,000 |
| 자석 크기 | 유효 선속 +10%씩, 출력은 선속 배율의 제곱 | 1,500 / 4,500 / 13,500 / 40,500 / 121,500 |
| 자석 재질 | 보너스 지속 300→360→420→480→540→600초 | 2,000 / 6,000 / 18,000 / 54,000 / 162,000 |
| 자동 흔들기 | 기준 속도로 자동 왕복, 수동 드래그 시 수동 조작 우선 | 2,500 |
| 자동 속도 | 자동 흔들기 해금 후 속도 +20%씩, 최대 ×2 | 3,000 / 9,000 / 27,000 / 81,000 / 243,000 |

감은 수는 1부터 표시 레벨까지 더한 값으로 발전 기본치를 바꿉니다. 곱배율과 분리되어 있으며, 코일 재질 등 배율은 이 기본치에 적용됩니다. 전선 굵기는 코일 Back/Front 외형 높이와 InductionArea 높이를 함께 늘리고 직접 출력 배율을 더하지 않습니다.

자석 크기 데이터는 유지되지만 현재 씬에 해당 구매 카드가 없습니다. 보너스 퀴즈 정답 처리에서 `GameManager.ActivatePowerBonus()`를 호출하면 지속시간과 ×2 배율이 적용됩니다. 현재 퀴즈 버튼에는 정답 처리 기능이 없습니다. 활성 중 재질 업그레이드 시 추가 지속시간을 남은 시간에도 더하며, 보너스 재적용은 시간을 갱신하고 배율을 중첩하지 않습니다.

계산 검증: `unity command script run --file Tools/Checks/InductionBalanceChecks.cs --entry InductionBalanceChecks.Run --format json`

통과 완료 시 별도 오브젝트 RewardPopupArea 안의 무작위 위치에서 노란 +전력W 텍스트가 생성되고, 위로 떠오르며 1.1초 동안 사라집니다. InductionRewardFeedback에서 색상, 글자 크기, 상승 거리, 지속시간을 설정하고, InductionArea의 BoxCollider2D로 발전 판정 범위를, RewardPopupArea의 BoxCollider2D로 글씨 생성 범위를 각각 조절합니다. 팝업 영역은 코일 높이 업그레이드와 독립적입니다. 텍스트는 8개 풀을 재사용하며 클릭을 가로채지 않습니다.

시작 보유 전력은 0입니다. 수동 드래그는 이동 속도 제한 없이 마우스의 Y 좌표를 즉시 반영하고, 위아래 이동 범위는 유지합니다. 자동 흔들기는 설정한 속도로 이동합니다.


획득 전력은 MagnetDragGenerator의 Reward Multiplier를 0.1로 설정해 기존의 1/10로 조정합니다. 빠를수록 보상이 커지는 비율, 통과 완료 정산 및 업그레이드 배율은 유지합니다. 1/50로 낮추려면 Reward Multiplier를 0.02로 변경합니다. WPS와 획득 팝업에도 조정한 실제 지급량을 사용합니다.



하단 InductionMeter는 최근 4초의 부호 있는 유도전류를 표시합니다. 회로 저항은 10Ω이며, 전압과 전류 숫자는 0.15초 구간의 RMS 값입니다. 전류 방향은 코일 선속이 증가/감소하는 방향에 따라 바뀝니다. 같은 극성의 이동 구간에서 V = 부호 × sqrt(P × R), I = V/R로 기존 발전 계산과 일치시킵니다. 숫자는 절댓값 실효값이고 그래프는 부호를 유지합니다. 게임용 등가 회로이며 실측 장비 수치가 아닙니다. 보상 배율 0.1은 재화에만 적용하고 전기 계기에는 적용하지 않습니다. 빠른 한 프레임 통과도 입구/중앙/출구 구간으로 나누어 양 극성 파형을 보존합니다.

전류 그래프는 각 측정 구간의 시작과 끝을 같은 값으로 표시하는 계단형 파형입니다. 곡선 보간은 사용하지 않습니다.

자동화의 엔딩 보기는 고정 가격 250,000W입니다. 업그레이드 비용이나 최대 발전량이 바뀌어도 가격은 변하지 않습니다. 최초 구매 시 비용을 한 번 차감하고 엔딩 화면을 엽니다. 계속 플레이로 닫은 뒤 같은 항목에서 무료로 다시 볼 수 있습니다.



큰 재화 숫자는 K(천), M(백만), B(십억), T(조) 등으로 축약하고 소수는 최대 두 자리까지만 표시합니다. 예: 1,250 → 1.25K, 250,000 → 250K, 3,125,000 → 3.13M. 표시만 반올림하며 실제 잔액·가격·구매 판정은 원래 수치 그대로 사용합니다.


자석의 월드 Y 이동 범위는 0~2.8입니다. 수동 드래그와 자동 왕복에 모두 적용합니다. 발전 통과 판정의 상하 경계는 InductionArea와 이동 가능 범위의 교집합을 사용하여 범위 밖으로 이동하지 않아도 정산할 수 있습니다.
